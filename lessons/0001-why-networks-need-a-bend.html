Why a network needs a bend

Depth buys you nothing at all until you break the straight line. This is the one idea the course deck skips — and everything else rests on it.

Your deck spends slides 19–25 building the perceptron, then slides 27–38 stacking perceptrons into layers, and then slide 41 introduces activation functions like this:

From the deck, slide 41

“For most use cases however that won’t be useful, we’ll want to be able to set constraints to our output values, especially in classification tasks.”

That makes the activation function sound like a formatting step — something you bolt onto the end to squeeze numbers into a tidy range. If that were all it did, you would only ever need one, on the output layer.

But the deck puts an activation function on every hidden layer too (look at the little S-curve glyphs on slide 107). Why? The real answer is not about formatting. It is this:

The one idea

Without a non-linearity between them, a stack of layers is mathematically identical to a single layer. A hundred-layer network with no activations can only ever draw a straight line. The activation function is not a finishing touch — it is the only reason depth exists.

1The collapse, in three lines

Take two layers, no activation. Layer one computes z₁ = W₁x + b₁. Layer two takes that as its input:

y = W₂(W₁x + b₁) + b₂
  = (W₂W₁)x + (W₂b₁ + b₂)
  =      W'x     +        b'

W₂W₁ is just another matrix. W₂b₁ + b₂ is just another vector. So your two-layer network is a one-layer network with different numbers in it. Add a third layer and it collapses again. Add ninety-seven more and it still collapses. You have spent a great deal of compute to fit a straight line.

Now put any non-linear function σ in between:

y = W₂ σ(W₁x + b₁) + b₂

There is no algebra that flattens this. The layers stop merging. Depth starts meaning something.

2See it collapse

Below is a real neural network — one input, N hidden units, one output — trained by actual gradient descent in your browser. The dashed line is the target curve. The solid line is what the network currently computes.

Do this in order:

  1. Leave it on ReLU with 8 units. Hit Train. Watch it find the curve.
  2. Switch activation to none (linear). Train again. Now push hidden units up to 24. It never stops being a straight line. That is the collapse, live.
  3. Back to ReLU, but drag hidden units down to 1. Train. You get exactly one bend. Now 2. Two bends. Count them as you go up.
  4. Try tanh at 8 units — same job, but the joins are smooth instead of sharp.

Nothing here is pre-recorded — the weights really are being updated by gradient descent on mean squared error, using Adam, which you will meet properly in Lesson 3.

3What one ReLU actually buys you

Step 3 above is the thing worth holding on to. A single ReLU unit computes max(0, wx + b): flat until wx + b crosses zero, then a straight ramp. One unit is one hinge — a single bend, at a position the network chooses by learning b/w, at an angle it chooses by learning w.

Add the hinges together with the output weights and you get a piecewise-linear curve. Ten hinges, ten bends. Enough hinges, placed well, and you can trace any curve you like as closely as you like — the same way a circle drawn with enough short straight segments looks round.

Carry this picture

A ReLU network does not learn a smooth formula for your data. It learns where to put the creases in a sheet of paper it then folds to match the shape of your problem.

4The theorem — stated properly

That intuition has a formal name, and your deck gets it wrong.

Correction — deck slide 39

The deck says networks can approximate any convex continuous function. Drop the word convex. The Universal Approximation Theorem applies to any continuous function on a bounded region. This matters: convex functions are bowl shapes, and almost nothing interesting in the real world is a bowl. If the theorem really were limited to convex functions, neural networks would be a curiosity rather than a technology.

Stated carefully: a network with a single hidden layer, given enough units and any non-polynomial activation function, can approximate any continuous function on a compact set to any accuracy you ask for.[1] The deck's names — Lu, Hanin — belong to a later, different version of the result: that you can also get there by keeping the network narrow and making it deep.[2]

5The catch that runs the rest of the course

Read the theorem again and notice what it does not say. It says a good set of weights exists. It says nothing whatsoever about you finding them.

That gap is the entire practical discipline of deep learning, and it is why the next three lessons exist:

The gapThe question it raisesWhere we handle it
Which non-linearity? Some bend the line but strangle the learning signal on the way back. Lesson 2
