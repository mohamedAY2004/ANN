The trap

Softmax makes the K outputs compete — they always sum to 1, so raising one lowers the rest. Correct when exactly one class is true, wrong for tagging. Sigmoid computes each output independently. Correct for tagging, wrong when the classes are exclusive.

2Hidden layers — this one is a choice

Why max slope is the column that matters

Backpropagation multiplies the error signal by f′(z) once per layer. A max slope below 1 means the signal shrinks every single time. Sigmoid's 0.25 compounds to 0.25¹⁰ ≈ 10⁻⁶ over ten layers — the early layers hear nothing. ReLU's 1.0 compounds to 1.0. That single fact is why deep learning works.

3Syntax

from tensorflow.keras import layers

layers.Dense(64, activation='relu')          # the normal way

layers.Dense(64)                                # or as a separate layer,
layers.LeakyReLU(negative_slope=0.1)           # which LeakyReLU requires

# Output layers, straight from the table above
layers.Dense(1)                                 # regression
layers.Dense(1, activation='sigmoid')           # binary
layers.Dense(10, activation='softmax')          # 10 exclusive classes
